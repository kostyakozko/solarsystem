# Solar System Suite Product Overview

## What is Solar System Suite?

A comprehensive, high-performance N-body gravitational simulation suite with real-time JPL HORIZONS ephemeris data integration and interactive web-based time travel visualization.

## Core Purpose

- **Scientific Simulation**: Accurate N-body gravitational simulation of the solar system
- **Real-time Data**: Integration with NASA JPL HORIZONS API for current ephemeris data
- **Interactive Visualization**: Web-based time travel interface for exploring solar system evolution
- **Professional Tools**: Suite of specialized applications for different use cases

## Key Applications

1. **solar_system_launcher** - Unified interface and workflow coordinator
2. **solar_system_fetch** - JPL data management and caching system
3. **solar_system** - High-performance batch simulation engine
4. **solar_system_realtime** - Live solar system tracking
5. **solar_system_web** - Interactive web-based time travel visualization

## Target Users

- Researchers and scientists studying orbital mechanics
- Educators teaching celestial mechanics and astronomy
- Developers building astronomical applications
- Space enthusiasts exploring solar system dynamics

## Key Features

- **27 Celestial Bodies**: Complete coverage of planets, moons, dwarf planets, and spacecraft
- **Time Travel**: Interactive visualization from any historical date
- **Smart Caching**: 1000-2000x performance improvement with binary/JSON cache system
- **Offline Capability**: Graceful fallback to hardcoded data when JPL API unavailable
- **Cross-platform**: macOS, Linux, Windows support
- **Zero Dependencies**: Built entirely with standard libraries
