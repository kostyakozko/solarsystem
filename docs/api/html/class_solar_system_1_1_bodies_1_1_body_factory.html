Detailed Description

Factory for creating celestial bodies from various data sources.

This class integrates with the existing JPL data system and provides a modern C++ interface for creating bodies from:

  • JPL HORIZONS data (primary)
  • Cached ephemeris data
  • Hardcoded fallback data (from constants.cpp)
