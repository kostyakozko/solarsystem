class Solar\+System\+::\+Utils\+::\+Expected$<$ T, E $>$}
C++20 compatible \doxylink{class_solar_system_1_1_utils_1_1_expected}{Expected} type for error handling without exceptions. 

This is a simplified version of std\+::expected (C++23) that works with C++20. It represents a value that can either contain a successful result or an error.
