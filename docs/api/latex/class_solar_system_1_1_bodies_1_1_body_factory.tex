\doxysubsection{Detailed Description}
Factory for creating celestial bodies from various data sources. 

This class integrates with the existing \doxylink{namespace_solar_system_1_1_j_p_l}{JPL} data system and provides a modern C++ interface for creating bodies from\+:
\begin{DoxyItemize}
\item \doxylink{namespace_solar_system_1_1_j_p_l}{JPL} HORIZONS data (primary)
\item Cached ephemeris data
\item Hardcoded fallback data (from constants.\+cpp) 
\end{DoxyItemize}
