\doxysubsection{Detailed Description}
Time Simulation Mock System for Testing. 

Provides comprehensive time mocking capabilities for time-\/dependent tests\+:
\begin{DoxyItemize}
\item Controllable time simulation for deterministic testing
\item Time travel and time manipulation capabilities
\item Clock freezing and time acceleration/deceleration
\item Integration with existing time-\/dependent components
\item Support for multiple time zones and epochs 
\end{DoxyItemize}
