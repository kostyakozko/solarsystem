\doxysubsection{Detailed Description}
Demonstration of the performance regression detection system. 

This example shows how to use the regression detection framework to\+:
\begin{DoxyItemize}
\item Store and compare performance baselines
\item Detect performance regressions automatically
\item Analyze performance trends over time
\item Generate CI-\/compatible reports 
\end{DoxyItemize}
